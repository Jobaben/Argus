# Shadow feeder

Controlled business scenarios for Argus H2 collection. Run `node select-case.mjs` only inside an Argus run. The selector uses the run UUID to vary tasks without editing shared files. Three scenarios are answerable and two cannot meet their requested deliverable from supplied facts. Agents must report honest outcomes rather than fabricate missing data or resolve contradictory requirements silently.

These traces are a controlled corpus, not production failure-rate evidence. Do not edit Argus run records, collection ledgers, snapshots or knowledge stores. H2 probes measure termination inference; residual cause correctness remains unmeasured. H1 requires genuine human gate decisions and is not enabled by this feeder.

The pipeline uses Claude / Haiku with a four-minute deadline and uses daily fixed slots at :00, :12, :24, :36 and :48 while the supplied launcher remains alive. Collection matures runs for ten minutes. The launcher sets a 96-call/day and US$10/day shadow allowance; workload calls are additional and remain subject to Argus's global budget. At least 200 probe answers per provider/question identity are needed for ECE, and each reliability bin needs 20 samples. No automatic promotion is performed.
