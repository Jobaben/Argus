# Troubleshooting

Symptom, cause and fix for the failures an author meets. Quoted messages are
worded as the code words them; `<i>` is a phase's position from 0, `<id>` its
id.

## Reading the evidence

Look before you change anything. In order:

1. `argus tail --for 0` — what is running, waiting and recently finished, with
   failure reasons verbatim. `argus tail --for 5m --until-idle` to follow a
   run. It returns when only gates wait.
2. `GET /api/instances/<id>` — the instance: each phase's `status`,
   `attempt`, `payload.failureClass` and reason, `verification` (every check's
   `detail` and output tail), `result`, `workspace`, and each step's `runId`
   and `completion` record (`marker`, `verdict`, `reason`).
3. `GET /api/instances/<id>/journal` — the history the instance record
   overwrites: `phase.failed`, `phase.retry-scheduled`, `step.timed-out`,
   `step.stalled`, `route.selection`, `route.skip`, `phase.approval-condition`,
   `children.*`.
4. `GET /api/instances/<id>/phases/<phaseId>/review` — what a waiting or
   failed phase left: payload, result, checks, artifact listing (`409` for a
   phase that is neither).
5. `GET /api/runs/<runId>` (the run and its log tail) and
   `GET /api/runs/<runId>/invocation` — what Argus launched: argv, `cwd`,
   environment names, the applied profile, `limitations`, `channels`, the
   workspace.

These reads need no account; send `Authorization: Bearer $ARGUS_TOKEN` when the
server has a token, for example
`curl -s -H "Authorization: Bearer $ARGUS_TOKEN" http://127.0.0.1:$ARGUS_PORT/api/instances/<id>/journal`.
Full shapes: [API § journal]({{argusRoot}}/docs/API.md#get-apiinstancesidjournal),
[review]({{argusRoot}}/docs/API.md#get-apiinstancesidphasesphaseidreview),
[invocation]({{argusRoot}}/docs/API.md#get-apirunsidinvocation).

## Saving: `validate`, `create`, `update`

| Symptom                                                                                                                                                                                                                                                                                   | Cause                                                                                                                                      | Fix                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `phase <i>: cwd does not exist: <path>`                                                                                                                                                                                                                                                   | The path is checked on the machine Argus runs on, now.                                                                                     | Use an existing absolute directory there. Long Windows paths, not `~1` short names.                                   |
| `phase <i>: needs at least one step` / `phase <i>: step prompt is required`                                                                                                                                                                                                               | An agent phase with no steps or an empty prompt. Only a spawn phase may have `steps: []`.                                                  | Add a complete step.                                                                                                  |
| `phase <i>: id must be 1-80 letters, digits, ".", "-" or "_" and start with a letter or digit`                                                                                                                                                                                            | Spaces or slashes in an id.                                                                                                                | Use a slug; put the label in `name`.                                                                                  |
| `duplicate phase id "<id>"`, `phase "<id>" needs "<dep>", which does not exist`, `phases form a cycle: …`, `no phase can start: every phase depends on another`                                                                                                                           | A broken graph.                                                                                                                            | Fix `needs`. Remember: one phase with `needs` makes every phase without it a root.                                    |
| `phase "<id>": needs "<src>" conditionally, but phase "<src>" declares no result`                                                                                                                                                                                                         | A `when` on an edge from a phase without `result`.                                                                                         | Add `result` to the source phase.                                                                                     |
| `phase "<id>": condition path "<p>" is not declared by phase "<src>"'s result schema`                                                                                                                                                                                                     | The predicate names a property the schema lacks.                                                                                           | Declare it under `properties`.                                                                                        |
| `phase "<id>": condition value for "<p>" must be a <type>` / `… is not one of its declared enum values`                                                                                                                                                                                   | `"true"` against a boolean, a typo against an enum.                                                                                        | Match the schema's type and enum exactly.                                                                             |
| `phase "<id>": needs "<src>": default, exclusive and required require a group`; `route group "<g>" members disagree on exclusive; every member must declare it`                                                                                                                           | Group flags used without `group`, or not on every member.                                                                                  | Name the same `group` on each edge and repeat the flags on each.                                                      |
| `phase "<id>": result.resultStep is required when a phase has more than one step`                                                                                                                                                                                                         | Several steps could write the result.                                                                                                      | Name the one step that decides.                                                                                       |
| `phase <i>: retry.retryOn must be a list of spawn \| exit-code \| …`                                                                                                                                                                                                                      | A class name the contract does not have (for example `configuration`).                                                                     | Use the listed classes; see [definition](definition.md#retry-classes).                                                |
| `phase <i>: stallSeconds must be an integer 30-86400`, `… timeoutSeconds must be an integer 1-86400`                                                                                                                                                                                      | Out of range, or not whole.                                                                                                                | Seconds, whole, in range.                                                                                             |
| `phase <i>: capabilities has unknown key "<k>"`, `phase <i>: checks[<j>] has unknown key "<k>"`, `phase <i>: workspace has unknown key "<k>"`                                                                                                                                             | A field in the wrong place (`timeoutSeconds` inside `capabilities`, `cwd` on an `artifact` check).                                         | Move it; see [definition](definition.md).                                                                             |
| `phase <i>: checks[<j>].path must be a relative path inside the directory`                                                                                                                                                                                                                | An absolute path or `..` in an `artifact`/`file` check.                                                                                    | Relative to the artifact directory or working tree.                                                                   |
| `phase <i>: additionalDirectories[<j>] does not exist: <path>`                                                                                                                                                                                                                            | Checked on the Argus machine at save.                                                                                                      | Create it, or drop it.                                                                                                |
| `…: env.set must not set reserved variable "<NAME>"`                                                                                                                                                                                                                                      | `ARGUS_*` control variables are Argus's.                                                                                                   | Remove it. Never put secrets in `env.set` either: the definition is readable without an account.                      |
| `phase <i>: candidates requires workspace.scope "attempt" on the phase or the pipeline …` / `… requires exactly one step …`                                                                                                                                                               | Best-of-N without its preconditions.                                                                                                       | One step, and `"workspace": { "scope": "attempt" }`.                                                                  |
| `phase <i>: approveWhen only means something on a gated phase`                                                                                                                                                                                                                            | `approveWhen` (or `autoApprove`) without `gated: true`.                                                                                    | Gate the phase.                                                                                                       |
| `phase <i> ("<id>"): approveWhen cannot open a gate that commits knowledge (…)`                                                                                                                                                                                                           | A knowledge phase must be approved by a person.                                                                                            | Remove `approveWhen` there.                                                                                           |
| `phase <i>: a spawn phase runs no agent of its own, so it cannot declare <field>; …`                                                                                                                                                                                                      | `retry`, `checks`, `gated`, `timeoutSeconds` … on a spawn phase.                                                                           | Put them on the child pipeline's phases.                                                                              |
| `phase "<id>": spawn.pipelineId names an unknown pipeline: <id>`                                                                                                                                                                                                                          | The child does not exist yet, or the id is a name.                                                                                         | Create the child first; use the id `create` printed.                                                                  |
| `phase "<id>": spawn.pipelineId names "<name>", which has a "<kind>" trigger; …`                                                                                                                                                                                                          | Children are started by the parent.                                                                                                        | Give the child `"trigger": null` or a webhook.                                                                        |
| `phase "<id>": spawn.key "<k>" must be a required string property of each task in phase "<src>"'s result schema` (and the `dependsOn`/`title` variants)                                                                                                                                   | The source schema does not declare the task shape the spawn reads.                                                                         | Declare `items` as an object with `key` in `required` and typed properties.                                           |
| `"<parent>" spawns this pipeline from phase "<id>", and this pipeline has a "<kind>" trigger; …`                                                                                                                                                                                          | Saving a child with a schedule or `after` trigger, or a spawn phase.                                                                       | Keep the child manual or webhook. `--force` does not bypass it.                                                       |
| `after trigger names an unknown pipeline: <id>`, `a pipeline cannot chain after itself`, `after trigger would create a cycle: …`                                                                                                                                                          | The source must exist and not loop back directly.                                                                                          | Create the source first; break the loop.                                                                              |
| `interval trigger needs everyMinutes >= 1`, `daily trigger needs time "HH:MM"`, `weekly trigger needs weekday 0-6`, `windowed trigger needs startTime/endTime "HH:MM"`, `webhook trigger does not take <field>`, `trigger.kind must be interval\|daily\|weekly\|windowed\|webhook\|after` | A malformed trigger.                                                                                                                       | Fix the shape; see [definition](definition.md#triggers).                                                              |
| Saved, but a field you wrote is gone from `argus pipeline show`                                                                                                                                                                                                                           | Unknown keys on the pipeline, a phase, a step, `retry`, `result`, an edge or `env` are dropped without error.                              | Diff `validate`'s output against your draft before `create`.                                                          |
| `409 instances-running` on `update`                                                                                                                                                                                                                                                       | An execution field changed while an instance of this pipeline, or a parent that spawns it, is live. Running instances keep their snapshot. | Wait, or `--force`: the edit applies to the next start only.                                                          |
| `401` "login required"                                                                                                                                                                                                                                                                    | Creating, updating, validating, starting, approving and revising need an Argus account session.                                            | Set `ARGUS_USER` and `ARGUS_PASSWORD` (a tool shell cannot answer the prompt).                                        |
| `401` "no account yet — create one to edit or run pipelines" (`auth_setup_required`)                                                                                                                                                                                                      | No account exists on this server yet.                                                                                                      | Ask the person to create the root account in the UI. Do not create one yourself.                                      |
| `401` "unauthorized", or `403` "forbidden: host not allowed"                                                                                                                                                                                                                              | Missing or wrong `ARGUS_TOKEN`, or the wrong URL or Host.                                                                                  | Pass `--url http://<host>:<port>` and `--token`; a non-interactive shell may not see the variables your terminal has. |
| `Connection refused` / unreachable                                                                                                                                                                                                                                                        | Argus is not running on that port.                                                                                                         | Ask the person; do not start a second server.                                                                         |

## Starting

| Symptom                                               | Cause                                                                                                 | Fix                                                                                  |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `409` "an instance is already running (overlap=skip)" | `overlapPolicy: "skip"` and an instance is running or waiting at a gate.                              | Finish, approve or abort it; or set `"allow"` if instances truly do not share state. |
| `412` "setup preconditions not met: …"                | A runtime CLI or its completion hook is missing or outdated.                                          | Relay the reasons; the person runs Setup in the UI.                                  |
| A scheduled pipeline never starts                     | `enabled: false`, `trigger: null`, the slot was missed by more than the grace window, or it was busy. | Check `enabled` and the trigger; start it by hand to test.                           |
| A pipeline started on its own right after `create`    | Saved with a trigger and `enabled` absent, which means `true`.                                        | Save new pipelines with `"trigger": null` or `"enabled": false`.                     |

## Running

| Symptom                                                                                                  | Cause                                                                                                                                                                                          | Fix                                                                                                                                                     |
| -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Class `unverified`: "completion refused as unverified: the final message has no ARGUS_OUTCOME marker; …" | The run stopped without the marker Argus asked for: truncated, ran out of turns, or the prompt dictated a reply format.                                                                        | Do not tell the agent "reply only with JSON"; put structured output in the result file. Raise `maxTurns`/timeout if it was cut off. Retried by default. |
| "… carries conflicting ARGUS_OUTCOME markers (…)"                                                        | The message names two outcomes, often because the prompt quoted the marker rule.                                                                                                               | Remove `ARGUS_OUTCOME` wording from the prompt; Argus adds the rule itself.                                                                             |
| "… the stop hook reported marker "<x>" but Argus read "<y>" …"                                           | An old or mismatched hook.                                                                                                                                                                     | The person re-runs Setup to reinstall hooks.                                                                                                            |
| Class `signal`: "completion refused: the final message reports …"                                        | The agent reported `failed` or `blocked`.                                                                                                                                                      | Read its reason. Fix the prompt, `cwd` or tools; `signal` is not retried by default on purpose.                                                         |
| `phase "<id>" did not deliver its declared result "<a>"`                                                 | No file at `ARGUS_RESULT_FILE`. Often a read-only Codex sandbox, or a profile blocking the write.                                                                                              | Check the invocation's `channels` for `unavailable`. On Codex use `workspace-write`.                                                                    |
| `result "<a>" does not match the declared schema: …` / `result "<a>": <parse error>`                     | The JSON is wrong or torn.                                                                                                                                                                     | Make the schema small and state each field's meaning in the prompt.                                                                                     |
| `the task list for spawn phase "<id>" is not usable: …`                                                  | Missing or repeated key, unknown `after`, a cycle, too many tasks, a task over 16 KiB.                                                                                                         | Tighten the plan prompt; keep `signal` in the source phase's `retryOn`.                                                                                 |
| Class `configuration`, never retried                                                                     | The launch could not be built as declared: an unenforceable profile under `strict`, a required channel unavailable, `cwd` not a git repository for a worktree, a `base` that does not resolve. | Read `limitations` in the invocation record. Fix the definition; `best-effort` only when the profile is intent, not a requirement.                      |
| Class `timeout`, journal `step.timed-out`, reason "timed out after Ns"                                   | `timeoutSeconds` elapsed.                                                                                                                                                                      | Raise it, or split the work. Add `timeout` to `retryOn` to retry.                                                                                       |
| Class `timeout`, journal `step.stalled`, reason "stalled: no output for Ns"                              | No transcript activity for `stallSeconds`; the process was alive but silent (a hung command, an interactive prompt).                                                                           | Find the hung command in the run log. Same class as a timeout.                                                                                          |
| Class `verification`                                                                                     | A check failed after the agent reported success.                                                                                                                                               | Read the check's `detail` and output. Retry only with `verification` in `retryOn`. Fix the check if it tests the wrong thing.                           |
| A `command` check fails although it passes in your terminal                                              | It runs in the worktree (not your checkout), under the phase's env policy (`inherit: "minimal"` drops variables), with a 600 s default timeout.                                                | Allow the variables it needs; set `timeoutSeconds`; install dependencies in the worktree first.                                                         |
| `changed-files` fails with nothing changed after a retry                                                 | A revise or `scope: "attempt"` measures from its own baseline.                                                                                                                                 | Expected: new work is asked for.                                                                                                                        |
| Work missing after the instance ended                                                                    | The worktree directory is removed; only committed work survives on `argus/<instanceId>/…`.                                                                                                     | Tell the agent to commit; check with `git diff --quiet HEAD`; or `"keep": true`.                                                                        |
| The worktree lacks your latest changes                                                                   | It is cut from `base` (default `HEAD` of `cwd`); uncommitted edits are not copied, and Argus never fetches.                                                                                    | Commit, or `git fetch` before starting.                                                                                                                 |
| A later phase cannot see an earlier phase's edits                                                        | The earlier phase declared its own `workspace`, or `scope: "attempt"`.                                                                                                                         | Put `"workspace": { "scope": "instance" }` on the pipeline and not on the phases.                                                                       |
| Fan-out branches overwrite each other                                                                    | Parallel phases edit one checkout.                                                                                                                                                             | Make branches read-only, or give each a worktree and merge deliberately.                                                                                |
| Steps of one phase interfere                                                                             | Steps in a phase run at the same time.                                                                                                                                                         | Put ordered work in separate phases.                                                                                                                    |
| Parallel Claude steps fail at startup reading `~/.claude.json`                                           | A known race between concurrent `claude -p` sessions (reliability WS13, open).                                                                                                                 | Keep `exit-code` in `retryOn`; narrow the fan-out.                                                                                                      |
| A step on Codex fails with a model error                                                                 | The pipeline's `model` is a Claude alias inherited by a Codex step.                                                                                                                            | Set `model` per step when runtimes are mixed; check `argus pipeline runtimes`.                                                                          |

## Gates

| Symptom                                                            | Cause                                                                                                  | Fix                                                                                                                                               |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Instance `awaiting-approval` and nothing moves                     | A gate waits for a person. `--until-idle` returns in this state.                                       | Relay the ⏸ line; approve or revise only when the person says so.                                                                                 |
| `approveWhen` gate never opens; journal `<label>: waiting: exit 2` | The script could not ask (CLI not signed in as the Argus user, expired credentials, wrong repository). | Run the script by hand in the worktree, as the Argus user.                                                                                        |
| Journal `not polled: this gate commits knowledge (…)`              | The attempt staged a knowledge delta.                                                                  | A person approves.                                                                                                                                |
| `autoApprove` gate waits                                           | No current verdict at or above the bar, or a trajectory hold.                                          | A person approves; see [API § Auto-approving gates]({{argusRoot}}/docs/API.md#auto-approving-gates).                                              |
| Phase failed under `approval-condition`                            | The poll exited with `failOnExit` (for example the PR was abandoned). Never retried.                   | Revise the phase, or abort.                                                                                                                       |
| `409 parent-decided` approving a child                             | Its parent no longer waits for it.                                                                     | Decide on the parent instead.                                                                                                                     |
| Spawn phase `awaiting-approval` with pause `children`              | A child failed or was aborted, and no child is live.                                                   | Revise the child, revise the spawn phase (re-run the rest), or approve it (accept the rest). `409 children-running` while a re-run child is live. |
| Revise did nothing visible yet                                     | Only the revised phase re-runs; its note is added to every later attempt's prompt.                     | Watch with `argus tail`.                                                                                                                          |

## Skipped is not failed

- **Skipped** (`route.skip` in the journal): a route did not select the phase,
  or everything it depended on was skipped. The instance can still succeed.
- **Failed**: the phase itself failed. Its dependents stay pending and the
  instance ends `failed` once nothing else can run. An `allowSkipped` edge
  does not accept a failed source.
- A required group with no match, or an exclusive group with two, fails the
  deciding phase, not its targets.
